# 🧮 Calculator Version 2

A simple and interactive calculator application built using **React**. This project performs basic arithmetic operations through a clean and user-friendly interface.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear button to reset the display
* 🖱️ Interactive calculator buttons
* ⚛️ Built using React components and state management

## 🛠️ Technologies Used

* **React**
* **JavaScript**
* **CSS**
* **Vite**

## 📦 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/calculator-version-2.git
```

### Navigate to the project folder

```bash
cd calculator-version-2
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm run dev
```
